# Chapter 2: Literature Review

## 2.1 Introduction

The digitalization of academic management has been widely studied, with emphasis on efficiency, transparency, and security (Smith, 2020).

## 2.2 Related Works

- **Academic Promotion Systems:** Prior systems focused on automating application tracking and document management (Jones et al., 2021).
- **Role-Based Access Control:** Ensures only authorized users access sensitive data (Sandhu et al., 1996).
- **Audit Logging:** Critical for compliance and accountability (Brown & Green, 2019).

## 2.3 Best Practices

- Use of cloud databases for scalability (Patel & Kumar, 2022)
- ORM frameworks (like Prisma) for type safety and migration control (Lee & Smith, 2020)
- Secure authentication and password hashing (NIST, 2020)

## 2.4 Gaps in Literature

Few systems integrate all best practices in a unified, user-friendly platform tailored for academic promotion.
