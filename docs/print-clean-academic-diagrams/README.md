# Print-Clean Academic Diagrams

This folder contains the recommended final diagram exports for Word. They are high-contrast grayscale versions designed for academic printing and PDF submission.

Use SVG first for Word because it stays sharp at any size. Use PNG only if Word has trouble with the SVG.

Figures 5, 6, and 7 are intentionally wide, open layouts. Place each on a landscape Word page, keep the aspect ratio locked, and size it to the available page width. Do not paste a screenshot or stretch the image vertically.
